#  Student Information System

A frontend **Student Information System** developed with **HTML, CSS, Bootstrap, and Chart.js**. The project provides a modern dashboard interface that allows students to view academic information through a clean and responsive user interface.

> This project focuses on frontend design and user interface development.

---

##  Features

- 🔐 Login page
- 📝 Registration page
- 🔑 Forgot Password page
- 📊 Student dashboard
- 📚 Course information
- 📈 GPA and credit information
- 📅 Attendance section
- 👨‍🏫 Advisor information
- 📝 Assignment progress tracking
- 📉 Academic progress chart
- 🔍 Search bar
- 📱 Responsive interface

---

##  Technologies

- HTML5
- CSS3
- Bootstrap 4
- JavaScript
- Chart.js

---

##  How to Run

1. Clone the repository.
2. Open `index.html` in your browser.
